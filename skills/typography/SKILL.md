# Экранная типографика

Пиши по-русски. При создании текста применяй правила языка и дизайн-системы; при аудите выдавай расхождения без самовольных правок. При просьбе исправить оформление сохраняй слова и смысл. Точное воспроизведение референса важнее типографических улучшений.

## Символы и пробелы

- Русские кавычки «…», вложенные „…“; английские “…” и ‘…’. Апостроф ’, если он нужен языку; в коде не меняй синтаксические кавычки.
- Дефис для частей слова; короткое тире для диапазонов 1–10; длинное тире для пунктуации с пробелами по правилам языка. Многоточие … вместо трёх точек в обычном тексте; код и введённые данные не преобразовывай.
- Используй × для размеров, − для математического минуса, ©/™/® по назначению. Для футов и дюймов используй обозначения единиц по языку и источнику.
- Один пробел между словами. Неразрывный пробел U+00A0 или HTML &nbsp; между числом и единицей, в инициалах и там, где разрыв разрушает смысл. Не оставляй короткие русские предлоги в конце строки, но не склеивай длинные последовательности в неразрывный блок.
- Переносы проверяй на фактической ширине. Не используй пробелы, табы и повторные br для раскладки.

## HTML и React

В JSX-тексте предпочитай реальные UTF-8 символы: `<p>Don’t</p>`. Последовательность backslash-u в обычном JSX-тексте выводится буквально; в JavaScript-строке внутри выражения она интерпретируется. HTML entities поддерживаются в JSX-разметке, но строка из данных с `&nbsp;` сама по себе не декодируется. Для данных используй реальные символы; не включай небезопасный HTML ради типографики.

## Шкала и набор

Шрифт, кегли, веса и интервалы бери из токенов проекта. Не заменяй системный шрифт ради оригинальности. Не вводи новые ступени без необходимости. Акцент делай экономно размером, весом и пространством. Не подчёркивай обычный текст ради акцента; ссылки должны оставаться узнаваемыми и доступными.

Для сплошного текста ориентир длины строки 45–90 знаков, но UI-лейблы и таблицы оценивай по задаче. `ch` приблизителен и не заменяет замер. Line-height подбирай по шрифту и токенам, а не одним коэффициентом на все компоненты. Кернинг включён; лигатуры проверяй по реальному шрифту. Капитель используй настоящую, трекинг прописных подбирай по гарнитуре. Для числовых таблиц — tabular-nums; числа выравнивай по смыслу колонки.

Выравнивание по началу строки — базовое. Центрирование оставляй коротким заголовкам, где оно оправдано. Отделяй абзацы отступом или интервалом; заголовок визуально связывай со следующим блоком. Списки и таблицы делай семантическими. Длинные слова, реальные русские строки, пустые состояния и обе темы проверяй в заданном объёме. Мобильную версию не добавляй без запроса.

Общие типографические ориентиры исходной версии связывались с Matthew Butterick, Practical Typography (https://practicaltypography.com). Здесь изложены правила применения к UI; фиксированные вкусовые рекомендации не считаются абсолютными.
