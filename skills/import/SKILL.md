# Импорт HTML в Figma

Используй для переноса готового HTML в редактируемый Figma-файл. Сначала проверь доступные методы коннектора, целевой файл и страницу. Если импорта HTML нет, прямо сообщи об этом; не обещай редактируемые слои из скриншота.

Для каждой запрошенной темы или фрейма подготовь отдельный импорт, сохранив контент и композицию. Изображения упакуй способом, поддерживаемым инструментом. Не используй фиксированные локальные пути, недокументированные API и непроверенные лимиты тарифа. Если нужен ручной шаг, давай по одному точному действию.

После каждого импорта нормализуй текст только в новых импортированных узлах. Сначала сними исходные font family, style, размеры, межбуквенные и межстрочные интервалы по диапазонам текста. Сверь реальные доступные шрифты; Semi Bold и SemiBold могут быть разными именами начертания. Загрузи нужные шрифты до изменения. Не заменяй всё на Inter Tight или Regular и не меняй существующие узлы страницы. Если шрифт недоступен, перечисли его, не подбирай замену молча.

Если требуется заставить Figma пересчитать интервалы, для fontSize > 0 перевод PIXELS в PERCENT равен value / fontSize × 100. AUTO и mixed обрабатывай отдельно, не округляй так, чтобы изменился перенос. Сначала проверь результат на одном импортированном фрейме. Сверь трекинг, line-height и переносы визуально. Это обход возможной проблемы рендера, а не безусловное требование менять единицы каждого текста.

Проверь Fill/Hug/Fixed, minWidth/minHeight и auto layout, сохраняя нужные фиксированные размеры. Переименуй импортированные секции по содержимому. Сверь все тексты с источником. После импорта правь Figma; HTML меняй только по запросу. В отчёте укажи импортированные узлы, несовпадения и способ визуальной проверки.
